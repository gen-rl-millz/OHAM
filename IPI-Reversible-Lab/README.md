The public Holo-Toffoli Map computes the eight-state permutation, its inverse, order, parity, cycles, S8 lexicographic index, and a two-word STASIS/FLUX distinction. The public Workbench executes editable three-bit involutions and Bennett compute–copy–uncompute using three registers.

**Scope limitation:** These are self-contained public companion implementations, not deployments of the private original FrameCore Holo-Toffoli Map and Rust-served Reversible Workbench. Neither an E8/Leech lift nor a native LEDGER receipt is synthesized. No unpublished lab dataset, private API, authentication token, QASM runtime, or high-dimensional source mapping is included.

Run the independent check: \`python3 IPI-Reversible-Lab/verify_public_demos.py\`. The checker uses only the Python standard library and tests all eight input states on every named programme.
