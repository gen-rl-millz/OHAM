# IPI-Tafoli-Deno — FrameCore Reversible Witness

This is a self-contained public synthetic demonstration associated with the independent FrameCore research programme. It is **not a deployment of proprietary FrameCore Rust crates or unpublished lab results**.

## Visit

Published by GitHub Pages at `https://gen-rl-millz.github.io/OHAM/IPI-Tafoli-Deno/` after Pages is enabled with **Deploy from branch** → **gh-pages** → **/(root)**.

The site demonstrates the classical Toffoli involution, Bennett compute–copy–uncompute, the exact affine-group and S8 closures, one synthetic source with two observer requests, and identity-of-result versus identity-of-history.

Run the independent verifier locally: `cd IPI-Tafoli-Deno && python3 verify_demo.py` (Python standard library only). It regenerates a JSON reference receipt and SHA-256.

**Scope:** Reversible finite-state computation, not quantum hardware, physical energy efficiency, or general cross-lattice equivalence. No private FrameCore laboratory files, tokens or repository data are included.
